# Botium Toys Security Controls Assessment

## Overview

This repository presents a security controls and compliance assessment conducted for the fictional organization 'Botium Toys'. 
The assessment was performed using the provided scope, goals, and risk assessment report to evaluate existing administrative, technical, and physical security controls.
The project identifies security control gaps, reviews compliance requirements, and provides recommendations to improve the organization's overall security posture.

* Note: This project is based on a fictional case study created for cybersecurity learning and portfolio purposes.


## Objectives

- Review the organization's risk assessment and audit scope.
- Evaluate existing administrative, technical, and physical security controls.
- Identify security control gaps and compliance deficiencies.
- Assess alignment with applicable security and compliance requirements.
- Recommend practical actions to strengthen the organization's security posture.


## Project Scope

The assessment covers the following areas:

- Existing administrative security controls
- Technical security controls
- Physical security controls
- Asset management practices
- Data protection measures
- Access control mechanisms
- Regulatory compliance requirements
- Risk identification and mitigation
